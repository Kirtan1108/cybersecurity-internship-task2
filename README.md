# Task 2: Phishing Email Analysis

## Objective
Analyze a phishing email sample and identify phishing characteristics.

## What I Did
- Examined a simulated PayPal phishing email
- Analyzed email headers for SPF/DKIM/DMARC failures
- Identified 10 phishing indicators including spoofed sender, malicious URLs, and social engineering tactics
- Used tools: MxToolbox, VirusTotal, URLVoid, PhishTank

## Tools Used
- MxToolbox Header Analyzer
- VirusTotal
- ICANN Whois Lookup
- URLVoid
- PhishTank

## Key Concepts
Phishing, Email Spoofing, Header Analysis, Social Engineering, Threat Detection
